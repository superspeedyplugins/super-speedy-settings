# Super Speedy Settings: engineering changelog

Started at 1.16.0. Earlier versions are recorded in the git history (one commit per version).

## 1.16.1 (27th November 2026)

> * The Knowledge Base link for Country Based Prices, Term Descriptions, Archives and Comments goes to the KB that documents them instead of a missing page.

Those four slugs have no KB category of their own, so `https://www.superspeedyplugins.com/kb/<slug>/` returned 404 (found in the launch session's final walk for Country Based Prices; the other three by checking every registered slug). `KB_PATHS` maps them to Super Speedy Ajax, Super Speedy Imports, Scalability Pro and the KB home. Every other registered slug's KB returned 200 on 27 November 2026.

## 1.16.0 (27 November 2026)

The Super Speedy screen in wp-admin becomes the onboarding and in-plugin sales experience for every
paid Super Speedy plugin.

- **Paginated screen.** Tabs on the existing Super Speedy page: Your plugins (the licence page, now
  with licence chips: Lifetime, Yearly until a date, "Free trial: N days left", "Free trial ended",
  Not licensed), For this site, Plugins (an index and one sales page per plugin), All Access, Free
  trial, and Deals (also a submenu item).
- **For this site.** Recommendations worked out on the server from the site's own facts
  (WooCommerce, published products, active plugins, cache plugin, page builder). Rule: a plugin not
  installed is recommended when it is marked always or replaces an active plugin, its WooCommerce
  requirement is met, and the product count reaches its minimum. Add-ons whose parent is not active
  are marked "Needs X". Nothing is sent.
- **Plugin pages.** Hero MP4 loop (muted, looped, source set only when scrolled into view, with
  poster), else the poster, else the first screenshot, else a branded panel; measured claims with
  their source links; features with Atlas icons (a sprite of the icons the bundled packs lack);
  screenshots; pricing; Try it free and Buy; previous and next.
- **Catalogue feed.** `assets/ssp-feed/catalogue-v1.json`, schema 1, fetched by WP-Cron twice a day
  as a bare GET with a generic user-agent, 10 second timeout, no redirects. No page load fetches it.
  A failed fetch keeps the last good copy and is shown on the page; invalid entries are skipped and
  named; media only from www. and videos.superspeedyplugins.com; claims need an https source on our
  site. Our screens send `Referrer-Policy: no-referrer`.
- **Free trial request.** A form that shows the exact JSON it sends and sends it only on Submit,
  from the server, to `ssp-trials/v1/request`. Site facts are optional and flat scalars.
- **Trial key pick-up.** On an admin load with no licence key stored, a plugin folder's
  `ssp-license-key.php` (added to a free-trial download) is read, its key stored, the pick-up
  recorded in `ssp_trial_from_zip`, and the file deleted.
- **Licence check.** The auth server's additive `licence` object (type, expires) is kept with the
  cached result.
- **Deals bubble.** A purple (#8035be) count on the Super Speedy menu and the Deals submenu: offer
  and launch items from the dashboard feed this user has not seen. Opening Deals clears it. Users
  who chose Hide offers get no bubble. WordPress's red update bubble is unchanged.
- **Dashboard box.** Links to "See what would speed up this site".
- **Fix: installed plugins shown as coming.** A launch tile for a plugin installed on the site is
  dropped (matched by the feed's optional product `slug`, else by name against installed folders
  and the catalogue), and a launch whose every product is installed is not shown or counted.
- **Fix: licence rows with no icon or support link.** Price Discounts, Country Based Prices, Super
  Speedy Analytics and Follow-up Emails are in the plugin list with names, icons and Live Support
  links (the Ajax Prices channel for the Ajax add-ons; the server invite for Analytics and
  Follow-up Emails, which have no channel yet).
- **Fix: every plugin's AI guide pointed at Super Speedy Filters.** New optional init arg
  `ai_guide_url` in `SuperSpeedySettings_1_0::init()`. The MCP setup screen links the guide of the
  plugin it was opened from (`&plugin=<slug>`), else the general guide
  (kb/super-speedy-basics/super-speedy-mcp/), and lists every plugin's own guide. Only https links on
  www.superspeedyplugins.com are used. Builds that pass nothing get the general guide.
